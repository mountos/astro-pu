新しいウェブサイトへようこそ！これは [Mountos Astro 基本テンプレート：PU 璞](https://pu.code.mountos.com) で作成されたデモページです。この記事は自由に編集・削除できます。

この記事の目的は、Markdown と Page Bundle アーキテクチャを活用して多言語コンテンツを記述する方法と、テンプレートに組み込まれた各種機能を紹介することです。

## これは H2 見出しです

Markdown で記述するだけで、Astro が自動的に洗練された HTML へ変換します。

### これは H3 見出しです

適切な見出し階層を構成することで、可読性と SEO の両面で大きな効果が得られます。

#### リスト

*   順序なしリストの項目
*   複数の項目を追加できます
    *   ネストしたリストも可能

1.  順序付きリスト
2.  番号は自動的に採番されます
3.  チュートリアルや手順の記述に最適です

#### 引用

重要な言葉や引用元を強調したいときは、blockquote を使用します。

> これは引用ブロックです。特別なスタイルで表示され、視覚的なアクセントになります。

#### コードブロック

技術記事や開発ドキュメントに欠かせないシンタックスハイライト付きコードブロックです。

```javascript
// JavaScript のコード例
function greet(name) {
  console.log(`Hello, ${name}!`);
}

greet('Astro');
```
