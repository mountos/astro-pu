欢迎来到您的新网站！这是一个使用 [Mountos Astro 基本模板：PU 璞](https://pu.code.mountos.com) 建立的示范页面。您可以自由编辑或删除这篇文章。

这篇文章的目的是展示您可以使用 Markdown 与 Page Bundle 架构撰写的各种内容格式，以及这个模板内建的各种功能。

## 这是一个 H2 标题

您可以透过撰写 Markdown 来建立文章。Astro 会自动将其转换为 HTML。所见即所得，非常简单。

### 这是一个 H3 标题

您可以有不同层级的标题来组织您的内容。这对于 SEO 和文章的易读性都很有帮助。

#### 列表

*   这是一个无序列表的项目
*   您可以有很多项目
    *   甚至可以有嵌套的列表

1.  这是一个有序列表
2.  顺序会自动被计算
3.  非常适合用来写教学步骤

#### 引用文字

有时候您想引用某人的话，可以使用 blockquote。

> 这是一个引用区块。它会以特殊的样式显示，来强调这段文字的重要性或来源。

#### 代码区块

对于技术博客来说，代码区块是不可或缺的。这个模板已经为您准备了优雅的语法高亮。

```javascript
// 这是一段 JavaScript 代码范例
function greet(name) {
  console.log(`Hello, ${name}!`);
}

greet('Astro');
```
